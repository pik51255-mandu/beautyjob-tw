# 離子燙與縮毛矯正：藥水、溫度、設計的差異

> 作者：20年資歷韓國髮型設計師 Jacob

## 先講結論

**離子燙和縮毛矯正用的是同一套化學——還原劑斷雙硫鍵、加熱塑形、中和劑接回來。真正的差別不在化學式，而在「運用」：藥水要不要分區、溫度要不要照髮況改、髮根髮尾要不要留設計。**

這件事很多助理搞不清楚，因為兩個名詞在美材行、在客人嘴裡、在網路文章裡都被混著用。有人說縮毛矯正是「日本來的高級離子燙」，有人說離子燙比較傷、縮毛矯正比較不傷——這些說法都只講對一半。藥水裡的還原劑成分可以完全一樣，一樣是切雙硫鍵；夾板一樣要加熱。差在你把這套化學當成一個「固定套餐」在跑，還是當成一組「可調參數」在設計。

現場的定位是這樣：**離子燙（陶瓷燙）在台灣仍是常備技術，但客人的印象普遍是「死板直」、損傷大；縮毛矯正是它的升級版操作，已經是現在「燙直」的預設值。** 名字換了不是行銷噱頭，是因為操作邏輯真的變了。

另外先擋一個最容易出事的誤會：**酸熱離子護（角蛋白離子護、離子護）不是燙髮，它是護髮。** 名字裡有「離子」兩個字，本質卻是另一種化學，這篇最後會用一張表把三者切乾淨。

## 同一套化學：燙直到底在做什麼

### 三個步驟，跟燙捲一模一樣

不管招牌寫離子燙還是縮毛矯正，骨架都是這三步：

1. **軟化（還原）**：塗一劑（還原劑），在鹼性環境下讓毛鱗片張開、藥水進入皮質層，把**雙硫鍵**切斷，頭髮進入可塑狀態。
2. **塑形（熱）**：沖水、吹到全乾，用夾板把髮流拉直。這一步靠的是熱與物理力量，讓斷開的鍵結兩端**移動到「直」的相對位置**，同時把氫鍵重排定位。
3. **定型（氧化）**：塗二劑（中和劑／氧化劑／定型劑），在新位置把雙硫鍵重新接起來，形狀固定。

鍵結那一層不熟的話，先補[頭髮的四種鍵結](/articles/hair-bonds-four-types)；流程細節在[燙髮三步驟](/articles/perm-three-steps)，還原與氧化的化學骨架看[一劑二劑在做什麼](/articles/oxidation-reduction-basics)。

### 為什麼燙直比燙捲難

同樣的化學，燙直的容錯率低很多，原因有三個：

- **直是「沒有地方藏」的形狀。** 捲度不均，客人看起來是自然；直度不均，客人一眼就看到某一區翹起來。
- **多了一道高溫。** 燙捲上捲子時頭髮是常溫或中低溫，燙直卻要把已經軟化過的頭髮再送進 150°C 以上的夾板。化學損傷疊上熱損傷，這是燙直損傷普遍比燙捲重的主因。
- **軟化過頭沒有退路。** 燙捲軟化過頭，捲度會鬆、會毛；燙直軟化過頭，加上夾板的拉扯與高溫，最直接的結果就是髮尾失去彈性、像海帶一樣垂下來，接下來只能靠[結構式護髮](/articles/bond-builder-chemistry)去填補與強化，把髮況撐到可以繼續服務的程度——但那是善後，不是還原。

所以燙直的成敗，八成壓在「軟化判斷」跟「溫度上限」這兩件事上。判斷方法在[軟化測試完整指南](/articles/softening-test-guide)，這裡不重複。

## 離子燙：單一藥水 ＋ 均一高溫

傳統離子燙的操作邏輯很單純，也很容易教：**整頭一支藥水、一個時間、一個溫度、一路夾到底。**

它會被說「死板直」，原因就在這個「均一」：

- **髮根被夾到底。** 夾板從離頭皮很近的地方就開始壓，髮根沒有支撐力，整頭扁塌貼頭皮，還常在轉折處留下折角（俗稱牛角、折痕）。
- **髮尾也被夾到底。** 沒有留任何彎度，髮尾像一片板子，剪過的層次全部被壓平，看起來就是一片。
- **不分髮況。** 髮根的處女髮和已經燙染過三次的髮尾，吃到同一支藥水、同一個時間，結果必然是一邊軟化不足、一邊軟化過頭。

那離子燙是不是就該淘汰？不是。它在台灣還留著，是有理由的：面對**極粗硬、極強自然捲、幾乎沒有燙染過的處女髮**，強藥水配足夠的溫度是最快、最穩、成本最低的解法。時間短、售價門檻低，對某些客層依然成立。它的問題從來不是化學不對，而是**把單一參數硬套在所有髮況上**。

## 縮毛矯正：把同一套化學拆成可調參數

縮毛矯正之所以能當成「升級版」，是因為它把上面那三個固定值全部打開，變成依髮況調整的參數。

### 參數一：藥水（種類、濃度、pH、分區）

這是差最多的地方。核心觀念是——**選藥水的依據是髮況，不是價目表。**

- **還原劑種類**：粗硬處女髮撐得住較強的還原劑；細軟髮、已經燙染過的頭髮，就要往作用溫和的方向走。各種還原劑的強度與適配髮質整理在[還原劑比較](/articles/reducing-agents-compared)。
- **pH 與鹼度**：鹼度越高，毛鱗片開得越大、藥水進得越快，但膨潤與流失也越大。受損髮要往中性、弱酸方向靠（可參考[pH與美髮](/articles/ph-and-hair-care)）。
- **分區塗抹**：這是縮毛矯正的招牌動作。髮根新生的處女髮塗強一點的藥水、髮中髮尾塗弱一點或稀釋過的，時間也錯開。同一顆頭上，兩支甚至三支藥水並存是常態。
- **中間護理介入**：軟化沖水後、上夾板前補一道結構式護髮，是現在很普遍的做法，目的是讓皮質層在高溫前先有東西撐著。

### 參數二：溫度（照髮況設，不是照習慣設）

夾板溫度不能只憑手感開。先記住頭髮在各個溫度會發生什麼事：

| 溫度區間 | 頭髮發生什麼 | 現場意義 |
|---|---|---|
| 約 120～150°C | 氫鍵斷開、重排 | 一般吹整、造型的作用區間 |
| 約 130°C 以上 | 角蛋白開始物理變性 | 超過這裡就不只是「造型」了 |
| 約 150°C 以上 | 毛鱗片開始劣化 | 觸感變粗、光澤下降的起點 |
| 約 200°C | 皮質層受損 | 彈性流失，回不來了 |
| 約 230°C | α螺旋不可逆變性 | 髮質崩壞的臨界線 |

乾髮造型時的一般建議是：**細軟髮或受損髮 150～160°C、一般髮質 170～180°C、粗硬髮 190°C 以內。** 更完整的熱損傷數據在[熱損傷科學](/articles/heat-damage-science)。

縮毛矯正還要再往下修一層，理由很直接：**軟化後的頭髮比乾髮脆弱得多。** 雙硫鍵已經被切開一部分，皮質層還處在膨潤狀態，這時候的耐熱度不能拿健康乾髮的標準去套。兩個絕對不能省的動作：

- **必須完全吹乾再上夾板。** 頭髮帶水進夾板，內部水分瞬間汽化，會從內部把結構撐開，這是最嚴重也最常見的燙直事故。
- **溫度要分區。** 髮根處女髮和漂過的髮尾用同一個溫度，等於拿粗硬髮的標準去燙受損髮。

### 參數三：設計（燙直不等於燙成一片）

離子燙做的是「拉直」，縮毛矯正做的是「決定哪裡直、哪裡不直」：

- **髮根留白**：從頭皮往下抓 1～2 公分不夾，保留支撐力，避免扁塌與折角。
- **髮尾留彎**：髮尾刻意留一點 C 彎，讓長度看起來有重量與收尾，而不是一塊板子。
- **分區操作**：只做瀏海、只做髮根、只做兩側，是很常見的需求，這在術語上就是「離子燙・縮毛矯正 分區操作」。
- **配合剪髮**：直度上來之後層次會變明顯，通常要重新調整輪廓。

## 一張表看完差別

| 項目 | 離子燙（陶瓷燙） | 縮毛矯正 |
|---|---|---|
| **化學骨架** | 還原→熱塑形→氧化 | 完全相同 |
| **藥水運用** | 整頭單一藥水、單一時間 | 依髮況分區，多支藥水並用、時間錯開 |
| **軟化判斷** | 多依既定時間 | 以測試軟化的狀態判斷為主 |
| **溫度設定** | 整頭均一、偏高 | 依髮況分區調整，受損區明顯降溫 |
| **中間護理** | 少 | 常規介入（結構式護髮等） |
| **髮根處理** | 夾到底，易扁塌、易留折角 | 留 1～2 公分不夾，保留支撐 |
| **髮尾處理** | 拉到全直 | 可留 C 彎，保留設計感 |
| **成品印象** | 死板直、一片感 | 自然直、有髮流與重量 |
| **適合髮況** | 粗硬、強自然捲的處女髮 | 幾乎全髮況，含燙染過的頭髮 |
| **損傷風險** | 高（強藥水＋高溫且不分區） | 可控（參數分區，但操作門檻高） |
| **維持** | 施術過的部分為永久性改變，新生髮另計 | 同上，通常 4～6 個月後補做髮根 |
| **操作時間・技術門檻** | 較短、較易標準化 | 較長，判斷力決定成敗 |

補一句最常被誤會的：**「縮毛矯正比較不傷」這句話不精準。** 它不是藥水比較溫和，而是「同樣的化學被更精細地分配」，所以整體損傷比較低。同一支藥水給一個不做判斷的人操作，縮毛矯正一樣可以把頭髮做壞。

### 髮況對應的參數設計（參考起點）

下面這張表是思考的起點，不是配方。實際數值一定要以測試軟化的結果為準。

| 髮況 | 藥水方向 | 夾板溫度方向 | 特別注意 |
|---|---|---|---|
| 粗硬處女髮 | 較強還原劑、足夠鹼度 | 可用上限偏高一段 | 軟化時間夠，否則直度不足、幾天後回捲 |
| 一般燙染過的頭髮 | 中等強度，髮尾降階 | 髮根與髮尾分兩段設定 | 髮尾優先降溫、縮短停留 |
| 細軟髮 | 溫和還原劑、低鹼 | 明顯調低 | 最怕扁塌，髮根留白要留足 |
| 反覆燙染的受損髮 | 稀釋、縮短時間，或分次施術 | 大幅調低，減少來回次數 | 先評估是否延後施術 |
| 漂過的頭髮 | 高風險，多數情況建議不做 | — | 雙硫鍵已被氧化成接不回來的形式 |
| 混雜白髮 | 白髮偏抗拒、質地硬 | 依整體髮況，勿只看白髮 | 與染髮的先後順序要先排好 |

最後一列要特別講：**漂過的頭髮做燙直，成功率跟一般髮完全是兩回事。** 漂髮的強氧化會把雙硫鍵的硫氧化成不可逆的形式，那不是「還沒接回來」，是接不回來了。結構式護髮能在斷開的位置填補、包覆、強化，讓頭髮撐得住後續服務，但它不會把已經失去的鍵結變回原本那條。這條界線要守住，不然你會對受損髮做出過度樂觀的判斷。原理在[漂髮科學](/articles/bleaching-science)。

## 不要跟「酸熱離子護」搞混

台灣現場有一組名字很像、本質完全不同的服務：**酸熱離子護／角蛋白離子護／離子護**。它是日本「酸熱トリートメント」的中文說法，屬於**護髮（トリートメント）**，不是燙髮。

它的化學跟前面兩者沒有交集：**它不切雙硫鍵。** 主流配方以乙二醛酸（glyoxylic acid）為主，在很低的 pH 下滲入，與角蛋白上的胺基反應形成**亞胺（imine）鍵**，再用夾板加熱脫水、重排二級結構。因為亞胺鍵是可逆的，洗幾次頭之後會慢慢鬆開——所以它是半永久性的。

| 項目 | 離子燙 | 縮毛矯正 | 酸熱離子護 |
|---|---|---|---|
| **本質分類** | 燙髮 | 燙髮 | 護髮 |
| **動到的鍵結** | 雙硫鍵 | 雙硫鍵 | 不動雙硫鍵，形成亞胺鍵 |
| **藥劑骨架** | 還原劑＋中和劑 | 還原劑＋中和劑（分區） | 酸性藥劑（乙二醛酸等）＋熱 |
| **pH 方向** | 一劑偏鹼 | 依髮況，中性～鹼性 | 強酸（部分產品 pH 低於 2） |
| **對強自然捲** | 有效 | 有效 | 有限，多為降低毛躁、增加順度 |
| **持久性** | 施術部位為永久性改變 | 同左 | 隨洗髮次數逐漸消退 |
| **主要目的** | 把捲拉直 | 把捲拉直＋設計 | 順度、光澤、抗毛躁 |

實務上兩個重點：

1. **別拿它去接強自然捲的單。** 客人拿著「酸熱護髮可以變直」的貼文來，你要先問清楚她的目標是「順」還是「直」。要直，那是縮毛矯正的工作。
2. **它有正在被討論的安全議題。** 乙二醛酸類產品近年在國際上出現與腎臟相關的不良事件通報與研究討論，部分國家已對含該成分產品採取管制。操作時避免碰到頭皮、保持通風，這是給客人也給自己的保護。細節整理在[酸熱離子護的真相](/articles/glyoxylic-acid-truth)。

## 台灣的濕氣，讓這個選擇更重要

台灣年均溫大約 25°C，濕度長期偏高，這對燙直的意義很具體：**吹直只動氫鍵，一出門碰到水氣就回去了；燙直動的是雙硫鍵，所以撐得住濕氣。** 這也是為什麼「自然捲怎麼辦」這個問題，在台灣最後幾乎都會走到燙直。

但反過來說，正因為客人真正的困擾是毛躁與膨脹，很多人其實不需要一頭死板直，只需要把毛躁壓下來、把髮流整理順。這時候用縮毛矯正的分區思維——只做容易膨的兩側跟後頸、髮尾留彎——會比整頭離子燙更貼近需求，損傷也小得多。濕度與氫鍵的完整關係在[高溫潮濕與髮型](/articles/humidity-frizz-science)。

教科書把三步驟的化學、溫度區間、藥水分類寫得很完整，這些是紮實的基礎，該背就要背。但書上不會告訴你的是：這一顆頭、這一區、這個當下，藥水該再放兩分鐘還是現在就沖，夾板該停在 150 還是 170。那個判斷靠的是手指拉開時的阻力、髮絲離開夾板時的回彈——書寫到這裡就停了，下面這一段留給現場。

## FAQ

**Q1. 離子燙和縮毛矯正到底是不是同一件事？**
化學上幾乎是同一件事，操作上是兩件事。兩者都靠還原劑切斷雙硫鍵、加熱塑形、再用中和劑接回來。差別在於離子燙是整頭單一藥水、單一溫度、一路夾到底；縮毛矯正把藥水、時間、溫度、夾板起點全部依髮況分區調整，並且刻意保留髮根支撐與髮尾彎度。所以同樣叫「燙直」，成品的自然度與損傷分布會差很多。

**Q2. 縮毛矯正可以撐多久？多久補做一次？**
被施術到的那一段頭髮，形狀改變是永久性的——它不會自己捲回去。會變的是**新生髮**。所以維持時間其實是「新生髮多明顯」的問題，一般大約 4～6 個月會需要補做髮根。重點是**只補新生的部分**，把整頭重複施術是損傷累積最快的做法。

**Q3. 漂過的頭髮可以做縮毛矯正嗎？**
多數情況建議不要，至少不要在同一次評估裡輕易答應。漂髮的強氧化會把雙硫鍵的硫氧化成接不回來的形式，中和劑再怎麼上也接不回失去的鍵結。若客人堅持，一定要先做小區段測試（挑一小束實際跑完整流程），並把可能的結果講清楚。結構式護髮能做的是在斷開處填補與包覆、把結構撐住，不是把頭髮變回沒漂過的狀態。

**Q4. 縮毛矯正當天可以染髮嗎？**
原則是**分開做，燙直優先，染髮往後排**。剛做完燙直的頭髮處在多孔、易吸色的狀態，同一天再上染膏，顏色容易吃太深、掉色也快。真的要在間隔不長的時間內染，就把雙氧乳的度數往下抓——例如用 **6%（20vol）取代 9%（30vol）**，寧可分兩次補色，也不要一次拉太多度數。度數的選擇邏輯在[雙氧乳設計邏輯](/articles/developer-volume-guide)。

**Q5. 客人說「我不要太直，可以嗎」——技術上怎麼做到？**
可以，而且這正是縮毛矯正的價值所在。可調的地方有三個：軟化程度（不做到全開，保留一部分雙硫鍵）、夾板起點與角度（髮根多留白、髮尾留 C 彎）、施術範圍（只做膨脹明顯的區塊）。先跟客人確認她要的是「順」還是「直」，再回頭決定這三個參數，順序不要顛倒。
