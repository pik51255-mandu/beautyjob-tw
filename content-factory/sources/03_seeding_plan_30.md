# beautyjob.tw 시딩 콘텐츠 30개 기획안 (v1)

**전제(버전 B):** 1차 독자 = 대만 현역 디자이너·어시스턴트·美髮技術士 수험생·이 분야를 배우려는 사람. 번체 중국어로 존재하지 않는 "모발과학 이론 커리큘럼"을 초·중·고급 시리즈로 구축해 검색 공백을 선점한다. 소비자 비교 키워드도 버리지 않되, 학습자 깊이로 쓴다.

**공통 원칙**
- 전 글 공개(로그인 게이팅 없음), 레벨 태그(初級/中級/高級)로 내비게이션만 분리
- 용어는 「대만 현지화 바이블」 섹션 1 대조표를 표준으로 사용 (軟化, 雙氧乳, 結構式護髮, 縮毛矯正 등)
- 발행 전 규제 금지어 체크: 生髮·育髮·活化毛囊·治療·再生·修復受損 → 強化·填補·護理·柔順으로 치환
- 글 구조 템플릿: 결론 먼저 → 원리 → 표/그림 → 현장 팁 → FAQ → 시리즈 내부링크
- 바이라인: "20年資歷韓國髮型設計師" (한결 브랜드 신뢰 자산 겸용)
- 글 1번이 허브(hub) — 모든 글에서 내부링크로 연결
