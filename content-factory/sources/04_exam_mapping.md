|---|---|

- [燙髮] "下列何項工作在冷燙操作中是不可少的過程，主要是看其捲曲程度 **①試捲**…" → #12 軟化·試捲 해설과 직결
- [染髮] "一般頭髮本身有四種麥拉寧色素粒子 → **黑、褐、紅、黃**" / "暖色調指含有 → **紅、黃**" → #16 색채학, #17 底色 해설과 직결

## 6. "기출 해설 버티컬" 구조 제안

- 시리즈명(안): **「美髮丙級學科解析」** — 연도별이 아니라 **단원별×주제별** 재구성
- 글 단위: 단원당 30~40題씩 묶어 2~5편 → 총 **약 22~25편** (818題 전량 커버)
  - 예: 燙髮篇 3편(원리·냉탕/軟化·試捲/열탕·안전), 染髮篇 3편(색채학/멜라닌·底色/염모제), 頭髮生理篇 3편, 洗護篇 3편, 公共衛生篇 4편, 기타 단원 각 1~2편
- 글 구조: 문항 원문(번체) → 정답 → **2~4줄 원리 해설** → 관련 이론 글 내부링크("깊이 알기 → #17 底色理論")
- 효과: 수험생 유입(해설) → 이론 시리즈 체류 → 플랫폼 회원 전환. 동시에 한국어 병기 해설판 = **선후님 본인 수험 교재** (컨텐츠 제작 = 시험 공부)
- 발행 배치: 이론 30편과 병행 — 이론 글 1편 발행 시 대응 해설 1편 세트 발행이 내부링크 효율 최적
